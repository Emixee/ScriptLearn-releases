# ScriptLearn — téléchargements

Ce dépôt contient uniquement les **installateurs et les mises à jour** de ScriptLearn,
le logiciel d'apprentissage de la programmation et du scripting (hors-ligne).

## Installer ScriptLearn

1. Ouvrez la [dernière version](https://github.com/Emixee/ScriptLearn-releases/releases/latest).
2. Dans **Assets**, téléchargez le fichier `ScriptLearn.Setup.X.Y.Z.exe`.
3. Lancez-le. Si Windows SmartScreen affiche un avertissement : « Informations complémentaires » → « Exécuter quand même ».

Aucun compte GitHub n'est nécessaire.

## Mises à jour

ScriptLearn vérifie lui-même ce dépôt et propose les nouvelles versions : aucune action manuelle n'est nécessaire.
